# CODSOFT Java Programming Internship

This repository contains the Java projects completed as part of the CodSoft Java Programming Internship.

## Tasks Completed

### Task 1 - Number Game
A simple number guessing game where the user tries to guess a randomly generated number within a limited number of attempts.

### Task 3 - ATM Interface
A console-based ATM system with options to:
- Check balance
- Deposit money
- Withdraw money
- Exit

### Task 5 - Student Course Registration System
A Java and MySQL based system for:
- Adding students
- Adding courses
- Viewing courses
- Registering for courses
- Dropping courses
- Viewing registered courses

## Technologies Used

- Java
- MySQL
